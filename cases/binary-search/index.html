WORKED CASE

Understand binary search by changing the view

Use an example, a visual interval, and teach-back to inspect the same mechanism.

The facts stay the same

  • The list is sorted in ascending order: [2, 5, 8, 11, 14].
  • The target is 11. Positions in this example count from 1.
  • Compare with the middle value; retain only the region that could contain the target.
  • Stop at a match or when no candidates remain.

Check your understanding

Why would this elimination rule fail if the list were unsorted?

Open the explained answer

A comparison with the middle item would no longer establish which other items are too small or too large. Discarding half could remove the target.
