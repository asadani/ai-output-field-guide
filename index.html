Follow the registration steps

First check whether this person already has a confirmed registration. If so, return the existing confirmation. Otherwise require an email address, then check remaining places. Confirm when a place is available; add to the waitlist when the workshop is full.

1. Check for an existing confirmation.
2. If it exists, return it without reserving a place.
3. For a new registration, require an email address.
4. If a place is available, confirm and reserve one place.
5. Otherwise, add the new registration to the waitlist.
